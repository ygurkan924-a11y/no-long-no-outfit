## 🖤 Marka Vizyonu & Felsefe

**NO LONG NO OUTFIT**, gereksiz detayları, ucuz trendleri ve gelip geçici logoları geride bırakıp doğrudan **duruşa, kumaşın tokluğuna ve kusursuz kalıba** odaklanan bağımsız bir lüks streetwear markasıdır.

Tüm koleksiyon:
- **280 – 450 GSM** ultra ağır pamuk süprem, 3 iplik şardonlu ve kanvas kumaşlardan üretilir.
- **Boxy & Drop-Shoulder** döküm kalıplarla tasarlanır.
- Sanforize terbiye ile yıkamalarda çekme ve form kaybı sıfıra indirilmiştir.

## ⚡ Temel Özellikler & Fonksiyonlar

### 1. 🛍️ Slide-Over Sepet Çekmecesi & Ücretsiz Kargo İlerlemesi
- Herhangi bir parçayı sepete eklediğinizde veya çanta ikonuna tıklandığında sağdan pürüzsüzce kayan cam efektli çekmece.
- Sepet tutarına göre ücretsiz kargoya kalan tutarı hesaplayan dinamik **İlerleme Çubuğu**.
- Tek tıkla miktar artırma/azaltma, ürün çıkarma ve doğrudan ödeme adımlarına geçiş.

### 2. 📏 Akıllı Beden Sihirbazı (Fit Finder Modal)
- Kullanıcının boy (155–205 cm) ve kilo (50–130 kg) değerleri ile stil tercihini (Tam Oturan, Boxy, Ultra Dökümlü) analiz eden akıllı boyutlandırma algoritması.
- Kişiselleştirilmiş beden tavsiyesi (`S` – `XXL`) üretir ve tek tıkla ürün sayfasına seçili beden olarak aktarır.

### 3. 🧥 İnteraktif "Shop The Look" / Hotspot Lookbook
- Editoryal FW26 Lookbook vitrininde kıyafetler üzerinde konumlandırılmış interaktif radar noktaları (`+`).
- Tıklandığında açılan cam kart ile parçanın kumaş gramajı, fiyatı ve özellikleri görüntülenip doğrudan sepete eklenebilir.

### 4. 🪡 Stüdyo Kombin Oluşturucu (Mix & Match Studio)
- Üst parçalar (Boxy Tee, Heavy Hoodie, Zip Hoodie) ile alt parçaları (Heavy Sweatpants, Cargo) aynı ekranda eşleştirebilme.
- Canlı silüet önizlemesi ve birlikte satın alımda **%10 Otomatik Kombin İndirimi**.

### 5. ⏱️ Sınırlı "Drop 02: Winter Vault" Geri Sayım & VIP Erken Erişim
- Canlı saniye saniye işleyen dijital geri sayım sayacı (`GÜN · SAAT · DAKİKA · SANİYE`).
- Yalnızca 250 adet üretilecek kışlık koleksiyon için şifreli VIP erken erişim davetiyesi (`NLNO-VAULT26`).
- Kilitli teaser arşiv kartları.

### 6. 💱 Çoklu Para Birimi Desteği (TRY, USD, EUR)
- Header ve mobil menüde anlık kur çevirici (`₺ TRY`, `$ USD`, `€ EUR`).
- Sitedeki tüm ürün kartları, çekmeceler, kombinler ve ödeme adımları seçilen kura göre anında hesaplanır.

### 7. 📦 Lüks "Mühürlü Mat Kutu" & Hediye Paketi
- Sepet ve ödeme adımlarında opsiyonel: *NLNO Mat Siyah Mühürlü Kutu & İpek Kağıt Paketlemesi (+79 TL)*.
- Özel tipo baskı hediye kartı notu desteği.

### 8. 🚚 Görsel Kargo & Sipariş Yolculuğu Zaman Çizelgesi
- Müşterinin sipariş kodunu sorguladığında görsel olarak takip edebileceği 5 adımlı interaktif lojistik çizelgesi (`Sipariş Alındı` → `Kalite Kontrol` → `Mühürlü Paket` → `Kargoya Verildi` → `Teslimat`).

### 9. 🧼 Kumaş & Yıkama Bakım Rehberi
- Ağır gramajlı kompakt penye ve şardonlu kumaşların yıllarca ilk günkü tok duruşunu koruması için 30°C ters yıkama, sererek kurutma ve buharlı ütüleme rehberi.

### 10. ⭐ Doğrulanmış Müşteri İncelemeleri & Beden Geri Bildirimleri
- Onaylı alıcı rozetleri, alıcıların boy/kilo ve beden eşleşmeleri (örn: *1.84m / 79kg · L Beden Aldı*).
- Ziyaretçilerin kendi deneyimlerini paylaşabileceği interaktif yorum formu.

### 11. 🔔 Canlı Satış Bildirimleri & Ziyaretçi Aciliyeti
- Ekranın sol alt köşesinde beliren minimalist canlı satın alma bildirimleri.
- Ürün sayfasında canlı inceleyen kişi sayısı ve son stok uyarıları.

### 12. 💬 WhatsApp VIP Stil Danışmanı
- Sağ alt köşede konumlanan tek tıkla stüdyo stilistine bağlanıp beden ve kumaş tavsiyesi alma imkânı.

## 🚀 Kurulum & Çalıştırma

Projeyi yerel ortamınızda çalıştırmak için:

```bash
# 1. Depoyu klonlayın
git clone https://github.com/KULLANICI_ADINIZ/no-long-no-outfit.git

# 2. Proje dizinine gidin
cd no-long-no-outfit

# 3. Bağımlılıkları yükleyin
npm install

# 4. Geliştirme sunucusunu başlatın
npm run dev
```

Tarayıcınızda [http://localhost:3000](http://localhost:3000) adresine gidin.

### Üretim Derlemesi (Production Build)

```bash
# Tip kontrolü ve optimize edilmiş üretim derlemesi
npm run build

# Üretim sunucusunu başlatın
npm run start

# Kod kalitesi kontrolü
npm run lint
```
